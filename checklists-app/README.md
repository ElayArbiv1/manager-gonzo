# Gonzo · צ'ק ליסטים לצוות (Netlify)

אפליקציה קטנה ונפרדת לצ'ק ליסטים בלבד, לטלפון של המלצרים והברמנים. היא משתמשת באותם מסכים של הצ'ק ליסטים באפליקציית הניהול (`../public/checklists.js`). הנתונים והתמונות נשמרים ב-Netlify Blobs, בלי שרת ובלי מסד נתונים חיצוני.

- **עובדים:** נרשמים עם שם וטלפון (וקוד צוות), ממלאים רשימות, מצלמים ומוסיפים הערות.
- **מנהלים:** מספרי הטלפון שמוגדרים ב-`MANAGER_PHONES`, וכניסה עם קוד מנהל. רואים את כל הרשימות שמולאו, מנהלים את הרשימות ורואים מי נרשם.

## העלאה ל-Netlify (פעם אחת)

1. ב-Netlify: **Add new site ← Import an existing project ← GitHub**, ובוחרים את `manager-gonzo`.
2. בהגדרות הבנייה:
   - **Branch to deploy:** הענף שבו נמצא הקוד
   - **Base directory:** `checklists-app`
   - את שאר השדות (Build command, Publish directory, Functions) Netlify קורא לבד מ-`netlify.toml`
3. **Environment variables** (בשלב הזה, או אחר כך ב-Site configuration ← Environment variables):

| משתנה | מה לשים | חובה |
|---|---|---|
| `SESSION_SECRET` | מחרוזת אקראית ארוכה. אפשר ליצור בטרמינל: `openssl rand -hex 32` | כן |
| `MANAGER_PHONES` | מספרי הטלפון של המנהלים, מופרדים בפסיק: `0501234567, 0529876543` | כן |
| `MANAGER_PIN` | קוד שמנהל מזין בכניסה, כדי שאי אפשר יהיה להתחבר כמנהל רק עם מספר טלפון | מומלץ מאוד |
| `TEAM_CODE` | קוד שעובדים מזינים בהרשמה, כדי שלא כל מי שיש לו את הקישור יוכל להיכנס | מומלץ |

4. **Deploy**. אחרי שינוי במשתנים צריך לעשות **Deploys ← Trigger deploy** כדי שייכנסו לתוקף.

## אחרי ההעלאה

1. נכנסים לאתר עם הטלפון של המנהל וקוד המנהל.
2. **ניהול רשימות ← ייבוא רשימה מקובץ**, ובוחרים את קובץ ה-JSON של הרשימות.
3. שולחים לצוות את הקישור ואת קוד הצוות. בטלפון: **שיתוף ← הוספה למסך הבית**, והאפליקציה נפתחת כמו אפליקציה רגילה.

## הרצה מקומית

```bash
cd checklists-app
npm install
MANAGER_PHONES=0501234567 npm run dev     # http://localhost:8888
npm test
```

בהרצה מקומית הנתונים נשמרים בתיקייה `.local-store/`.

## מגבלות בגרסה הראשונה

- מספר הטלפון לא מאומת ב-SMS. עובד יכול להירשם עם מספר של עובד אחר. קוד הצוות וקוד המנהל מצמצמים את זה.
- כל עובד רואה רק את הרשימות שהוא מילא. מנהל רואה הכל.
