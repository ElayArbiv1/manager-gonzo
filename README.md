# Gonzo · אפליקציית ניהול

אפליקציית ניהול לעסק: סיכומי מכירות שבועיים, שעתי עבודה יומי ועלות עבודה, דוחות ביטולים, תחזית ותכנון משמרות, הוצאות ויומן משמרת. כל דוח ניתן לייצוא ל-Excel.

## הפעלה

דרוש Node.js 20 ומעלה.

```bash
npm install
npm run demo      # אופציונלי: טוען 4 שבועות של נתוני דוגמה
npm start         # http://localhost:3000
```

הגדרות סביבה:

| משתנה | משמעות |
|---|---|
| `APP_PASSWORD` | סיסמת כניסה. **חובה** אם האפליקציה נגישה מהאינטרנט |
| `PORT` | פורט (ברירת מחדל 3000) |
| `HOST` | `0.0.0.0` כדי לאפשר גישה מטלפון באותה רשת או מהענן (ברירת מחדל: רק מהמחשב עצמו) |
| `DATA_DIR` | תיקיית מסד הנתונים (ברירת מחדל `./data`) |

כל הנתונים נשמרים בקובץ אחד: `data/gonzo.db` (SQLite). כדי לגבות, מעתיקים את הקובץ הזה.

## מה יש באפליקציה

| מסך | מה רואים |
|---|---|
| **לוח בקרה** | מכירות, הזמנות, ממוצע להזמנה, שעות ועלות עבודה, % עבודה מהמכירות, מכירות לשעת עבודה, ביטולים. כל מדד מושווה לתקופה הקודמת. מופיעות גם התראות אוטומטיות |
| **מכירות** | פילוח לפי מקור (קופה / אתר / וולט...), לפי שעה, לפי יום בשבוע, ערוצים, אמצעי תשלום, פריטים וקטגוריות מובילים |
| **שעות ועלות עבודה** | שעתי יומי, לפי עובד, לפי תפקיד, רשימת כל המשמרות, וזיהוי משמרות חריגות (מעל 12 שעות) |
| **ביטולים** | לפי יום, עובד, סיבה ופריט, ורשימה מלאה |
| **תחזית ותכנון משמרות** | מכירות צפויות לשבוע הבא לפי ממוצע 8 שבועות, תקציב עבודה ושעות מומלצות ליום |
| **ייבוא דוחות** | העלאת CSV או Excel עם זיהוי עמודות אוטומטי (עברית ואנגלית), תצוגה מקדימה, היסטוריה ומחיקה |
| **עובדים** | שכר לשעה ותפקיד. עובדים נוספים אוטומטית מדוח המשמרות |
| **הוצאות** | חשבוניות ספקים לפי קטגוריה, Prime cost ורווח גולמי משוער |
| **יומן משמרת** | הערה יומית, ספירת קופה, מזג אוויר או אירועים |
| **הגדרות** | מע״מ, יעד % עבודה, מקדם עלות מעביד, יעד מכירות שבועי, סף התראת ביטולים |

### איך מחושב מה

- **עלות עבודה** = שעות × שכר לשעה × מקדם עלות מעביד (ברירת מחדל 1.25). אם בדוח המשמרות יש עמודת עלות, משתמשים בה כמו שהיא.
- **% עבודה** = עלות עבודה ÷ מכירות **ללא מע״מ**.
- **העלאה חוזרת** של קובץ מחליפה את הנתונים מאותו מקור באותו טווח תאריכים, כך שאין כפילויות. אפשר לבטל את זה בתיבת הסימון.

## העבודה השבועית

1. מייצאים מביקום את דוח המכירות היומי (Z), דוח מכירות לפי פריט ודוח ביטולים, לשבוע האחרון, כ-Excel.
2. מייצאים מהאתר את רשימת ההזמנות לשבוע.
3. מייצאים מאפליקציית המשמרות את דוח הנוכחות (כניסה / יציאה).
4. מעלים את כל הקבצים במסך "ייבוא דוחות". הסוג מזוהה לבד.
5. בלוח הבקרה לוחצים "שבוע קודם" ואז "Excel" כדי לקבל סיכום מוכן לשליחה.

אפשר גם לייבא משורת הפקודה, כדי לאטמט את התהליך:

```bash
npm run import -- ~/Downloads/z-report.xlsx --source beecomm
npm run import -- ~/Downloads/attendance.csv --source shift
```

## חיבורים אוטומטיים (ביקום / אפליקציית משמרות)

**המצב היום:** לביקום (Beecomm) אין API ציבורי פתוח. גישה לנתונים דרך API ניתנת רק לשותפי אינטגרציה, בתיאום מול ביקום. גם רוב אפליקציות המשמרות בארץ לא מפרסמות API פתוח. לכן הגרסה הזו עובדת עם קבצי ייצוא, וזה עובד עם כל מערכת.

**למה לא מתחברים עם שם המשתמש והסיסמה?** אפשר טכנית לבנות "רובוט" שמתחבר לממשק הניהול ומוריד דוחות, אבל:
- זה כנראה מפר את תנאי השימוש של הספק.
- זה נשבר בכל שינוי באתר שלהם.
- זה דורש לשמור את סיסמת הניהול של הקופה בשרת.

**הדרך המומלצת:**
1. לפנות לתמיכה של ביקום ולבקש **API / גישת אינטגרציה לדוחות מכירות וביטולים**, או **שליחת דוח Z אוטומטית למייל** כל לילה (הרבה קופות תומכות בזה).
2. לבדוק את אותו הדבר מול אפליקציית המשמרות: API, webhook או ייצוא מתוזמן למייל.
3. אם יש דוח במייל: אפשר להוסיף לאפליקציה תיבת דואר ייעודית שקוראת את הקבצים ומייבאת לבד, דרך `scripts/import.js`.
4. אם מקבלים API: מוסיפים מחבר ב-`server/connectors/` שממיר את התשובה לאותם שדות שהייבוא משתמש בהם (`normalizeRows` → `commitImport`), ומריצים אותו פעם ביום.

```
  reports.js     כל החישובים והדוחות
  export.js      ייצוא Excel
  auth.js        סיסמת כניסה
public/          ממשק (HTML/JS, RTL, Chart.js)
scripts/         ייבוא משורת פקודה ויצירת נתוני דוגמה
test/            בדיקות
```
